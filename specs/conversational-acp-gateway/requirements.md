# GRAPHOS-ACP requirements

| ID | Requirement | Verification |
|---|---|---|
| `GRAPHOS-ACP-R001` | **Conversational ACP gateway session admission and policy.** GraphOS admits an ACP session only for a verified principal from the existing identity path, binds the session immutably to that principal/tenant/scope snapshot, enforces configured idle and absolute expiry limits, and returns one typed `chat_adapter_unavailable` refusal for admission and messages whenever the agent-utilities chat adapter is absent or unreachable, without a local reply or REST fallback. Split into `GRAPHOS-ACP-R001.1` (the graph-os-owned typed session-policy model and admission/refusal check) with the transport wiring to the real ACP endpoint and the identical REST-path projection check remaining open under the parent until `GRAPHOS-ACP-R001.2`'s dependency is satisfied. | Unit and integration tests cover admission refusal for missing/invalid credentials, immutable binding, idle-expired refusal, absolute-expired refusal, the typed adapter-unavailable refusal on both admission and message, identical principal/tenant/scope projection against the REST path, and a status/doctor read that reports adapter and limit state without secrets. |
| `GRAPHOS-ACP-R001.1` | **Typed ACP session-policy model and fail-closed admission check.** graph-os defines the typed `PrincipalContext`/`AcpSessionPolicy`/`AcpSessionSnapshot` model and an `AcpSessionAdmission` that admits only a verified principal, binds the session immutably, enforces idle/absolute expiry, and refuses with a distinct `chat_adapter_unavailable` reason — on both admission and message — whenever the caller-supplied chat-adapter probe reports unavailable, with no transport wired yet. | Proven by unit tests asserting unauthenticated refusal, immutable principal binding, idle- and absolute-expiry refusal, and the dedicated `chat_adapter_unavailable` refusal on both admission and message. |
| `GRAPHOS-ACP-R001.2` | **RETIRED: tracked by agent-utilities AU-CONTROL-001.** Owner dependency: agent-utilities chat adapter. `GRAPHOS-ACP-R001`'s transport wiring and end-to-end session flow depend on agent-utilities exposing a reachable chat-adapter contract, owned by `AU-CONTROL-001` (agent-control-plane). This child tracks that external dependency and stays open — no graph-os transport code is delivered against it — until agent-utilities delivers the adapter contract graph-os's admission check can probe. | Closes by reference to `AU-CONTROL-001` evidence of a reachable chat-adapter contract; no graph-os-side test is bound to this child. |
