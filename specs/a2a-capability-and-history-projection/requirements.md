# GRAPHOS-A2A-003 requirements

| ID | Requirement | Verification |
|---|---|---|
| `GRAPHOS-A2A-R001` | **Advertise only what is wired.** graph-os's Agent Card sets `capabilities.streaming`, `capabilities.pushNotifications`, and `capabilities.stateTransitionHistory` true only when a real durable authority object implementing the matching protocol (`A2AStreamingAuthority`, `A2APushNotificationAuthority`, `A2ATransitionHistoryAuthority`) is wired into the running composition; no flag or partial authority can force a field true. Split into `GRAPHOS-A2A-R001.1` (the typed capability-advertisement model, landed in this PR). | Proven by unit tests over `A2AAgentCapabilities.from_wired_authorities` asserting default-false, per-authority true, and a `TypeError` refusal on a non-conforming object. |
| `GRAPHOS-A2A-R001.1` | **Typed Agent Card capability-advertisement model.** graph-os defines `A2AAgentCapabilities.from_wired_authorities` plus `A2AStreamingAuthority`/`A2APushNotificationAuthority`/`A2ATransitionHistoryAuthority` runtime-checkable protocols in `graph_os/a2a/models.py`, so a capability field is derived from whether a conforming authority object was supplied, never from a bare boolean. | Proven by `tests/a2a/test_models.py` covering default-false, selective true, all-true, and refusal on a non-conforming authority. |
| `GRAPHOS-A2A-R002` | **WorkItem stream projection, not a shadow log.** graph-os's `message/stream` and push delivery read agent-utilities' WorkItem event stream (`AU-CONTROL-001`) through its public port for status, step and terminal-outcome updates, storing no independent event-log copy; a projection gap surfaces as typed `UNAVAILABLE`. | Proven by integration tests against a scripted AU WorkItem event fixture asserting projected events match the fixture and a missing/stale event yields `UNAVAILABLE`, never a backfilled value. |
| `GRAPHOS-A2A-R003` | **Transition history is read-through to epistemic-graph.** graph-os's `tasks/get` history path reads a task's full state-transition ledger through to epistemic-graph's durable kernel (`EG-DURABLE-KERNEL`) with no local reconstruction. | Proven by a contract test against a scripted EG durable-kernel fixture asserting the returned history exactly matches the fixture ledger. |
| `GRAPHOS-A2A-R004` | **Typed refusal when the durable history authority is absent.** When no `A2ATransitionHistoryAuthority` is wired or the wired authority is unreachable, graph-os returns a distinct JSON-RPC error `A2ATransitionHistoryUnavailable` with a privacy-safe message, never an empty or partially reconstructed history. | Proven by a negative test asserting the distinct error code and message shape, and that no history data is returned. |
| `GRAPHOS-A2A-R005` | **Push notifications are best-effort over a durable outbox.** graph-os retries push delivery from epistemic-graph's durable outbox (`EG-DURABLE-KERNEL-R001`), never an in-process queue; a repeatedly failing target is dead-lettered and reported. | Proven by a restart test asserting pending pushes survive process restart via the outbox, and a repeated-failure test asserting dead-letter reporting. |
| `GRAPHOS-A2A-R006` | **No capability advertised before GRAPHOS-A2A-002 lands.** Until `GRAPHOS-A2A-002`'s context-budget subset is on the default branch, graph-os's composition layer refuses to wire a real streaming/push/history authority, keeping all three capability fields fixed false. | Proven by a composition-layer test asserting authority wiring is refused (or absent) while the `GRAPHOS-A2A-002` dependency flag is unset. |
| `GRAPHOS-A2A-R007` | **Caller-visible card matches served behavior.** A contract test asserts the Agent Card's advertised capability subset exactly matches which of streaming/push/history the integration fixture actually exercises at the tested revision. | Proven by a contract test comparing advertised capabilities against the fixture's exercised capability set at the exact tested revision. |
