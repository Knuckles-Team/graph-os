# GRAPHOS-DATA-MARKET requirements

| ID | Requirement | Verification |
|---|---|---|
| `GRAPHOS-DATA-MARKET-R001` | **Durable, deduplicated flip alert delivery.** graph-os subscribes durably to the finance flip event topic and delivers alerts to configured notification channels, deduplicating by tenant, event ID, and subscriber so a restart cannot cause a duplicate user-visible alert. An alert never authorizes an order or changes a portfolio. | Proven by a restart/redelivery test confirming at-least-once transport with idempotent, deduplicated delivery. |
| `GRAPHOS-DATA-MARKET-R002` | **Scheduled finance backfill, scan, and explanation jobs.** graph-os schedules finance backfill, scan, and flip-explanation jobs through its existing scheduler, recording each schedule's tenant, owner, authorized action, timezone, trigger, idempotency key, and last run, so a daylight-saving transition or replay cannot duplicate an effect. The explanation itself is produced by the agent workflow and must cite its exact calculation inputs. | Proven by a scheduler test crossing a daylight-saving transition and a replay test confirming no duplicate job execution. |
| `GRAPHOS-DATA-MARKET-R003` | **Server-side finance and markets reads and paper order submission.** graph-os serves tenant-scoped market and finance reads, and paper order submission, through graph_os/api/ops/finance.py and markets.py, with the market read logic ported server-side into graph_os/finance/markets.py. Each read requires the finance:read grant and returns a typed unavailable result before any provider call when tenant or account binding is unverified; paper order submission requires a tenant-bound account and the finance:paper-trade grant. | Proven by two-tenant tests confirming zero cross-tenant reads and a negative test confirming unverified account binding returns unavailable before any provider call. |
| `GRAPHOS-DATA-MARKET-R004` | **One-at-a-time application admission with rollback.** graph-os admits one named application and its data source into the shared data plane at a time, using a dry-run plan, an idempotency key, explicit approval, health and parity probes, and a rollback fence. An application's existing ingest connector is retired only after the admitted source is healthy, parity checks pass, and the retirement is approved. | Proven by a restart/fault test demonstrating a failed admission rolls back without retiring the prior connector. |
| `GRAPHOS-DATA-MARKET-R005` | **schema_context query surface for tables and ontology mappings.** graph-os serves an authenticated schema_context query over REST and MCP that answers a table or object's definition, joins, ontology class mapping, owning application, and change impact, labelling any unverified or inferred relationship as a proposal rather than an approved fact. If the graph engine has no schema-context capability or approved catalog snapshot for the source, graph-os returns a typed unavailable result instead of fabricating an answer. | Proven by contract tests covering each intent (definition, joins, ontology, owner, impact) and a negative test for an unsupported source returning a typed unavailable result. |
| `GRAPHOS-DATA-MARKET-R006` | **Recurring DCA plans with deterministic, non-duplicating proposals.** graph-os stores a recurring dollar-cost-averaging plan's owner, tenant, symbol, account binding, decimal amount and currency, timezone, recurrence rule, bounds, pause state, and paper or live mode, and produces one durable proposal per due occurrence with a key derived from the plan revision so replay or clock drift cannot create a duplicate. Paper mode executes only under the paper grant and lease; live mode stays proposal-only until a human approves the exact preview and a connector consumes a write-back lease through the governed path in AU-CONTEXT-R006. A missed or failed contribution is reported, never silently skipped or doubled. | Proven by a replay and clock-drift test asserting exactly one proposal per occurrence, and a fault test confirming a missed contribution is reported rather than silently dropped. |
